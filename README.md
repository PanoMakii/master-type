# Master Type

Typing speed tester in plain HTML, CSS and JavaScript. No build step: open `index.html`.

- Modes: timed (1/3/5/15 min), pages (1-3), 10-key (basic/advanced)
- Text: Wikipedia API by topic, with offline fallback text
- WPM = correct characters / 5 / minutes. Accuracy = correct keystrokes / all keystrokes
- Accounts and results are stored in localStorage (demo). Replace `Auth` and `Api.getLeaderboard` with real backend calls later
